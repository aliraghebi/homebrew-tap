# aliraghebi/homebrew-tap

Homebrew tap for [splitroute](https://github.com/aliraghebi/splitroute): keep chosen IP ranges outside your
VPN, or drop them, on macOS.

## Install

```sh
brew install --cask aliraghebi/tap/splitroute
```

## Upgrade

```sh
brew upgrade --cask splitroute
```

## Uninstall

```sh
sudo splitroute uninstall      # if you installed the service: stops it and removes the routes
brew uninstall --cask splitroute
```

Usage and configuration: [splitroute README](https://github.com/aliraghebi/splitroute#readme).
